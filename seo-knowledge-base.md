## 11. On-page messaging rules

To keep the project credible and search-friendly, use language like:
- Riverside Azure is a residential development at 25 Riverside Drive, Nairobi.
- Riverside Azure offers 1, 2 and 3-bedroom apartments in Riverside, Nairobi.
- The project includes premium amenities and a residential lifestyle focus.

Avoid keyword stuffing, exaggerated promises, and unsupported ROI claims.

## 12. Conversion goals to keep in mind

The site is not only a content site. It is a sales-focused property website. SEO pages should direct users to:
- inquiry form
- WhatsApp or direct contact
- brochure request
- unit enquiry
- viewing request

This means each SEO landing page should answer the search question and then lead to the strongest conversion action.
